# LineStockAgent 主要功能與技術規格 (Features & Tech Spec)

本文件條列說明 `LineStockAgent` 專案目前提供的主要功能，並特別著重於其背後所使用的核心技術架構以及串接的 AI 人工智慧功能。

---

## 一、 主要功能模組 (Key Features)

### 1. 股票記帳與投資組合管理 (Portfolio Management)
*   **功能描述**：讓使用者透過 LINE 介面登記股票的買進與賣出。系統會自動計算各持股的平均成本、未實現損益、庫存股數等。
*   **交割金額試算**：系統支援「未來交割總額」試算，讓使用者在 T+2 制度下能清楚掌握未來幾天內應付或應收的淨額，避免違約交割。
*   **技術實作**：使用本機端 `SQLite` 資料庫 (`taicai.db`) 儲存交易歷史 (`history`) 與庫存狀態 (`inventory`)。

### 2. 個股關注清單 (Watchlist)
*   **功能描述**：使用者可將感興趣的股票加入關注清單，方便隨時追蹤。
*   **技術實作**：透過本機資料庫維護清單，並可與後續的 AI 個股健檢功能連動。

### 3. 專屬視覺化儀表板 (Web Dashboard)
*   **功能描述**：當使用者在 LINE 中輸入「開啟專屬資料庫」或「儀表板」時，會獲得一個專屬的網頁連結。點開後可透過豐富的視覺化介面 (HTML/JS/CSS) 查看完整的投資組合、交割金額與大盤趨勢。
*   **技術實作**：
    *   後端：使用 `FastAPI` (Uvicorn) 提供 `/api` 路由與資料存取。
    *   前端：透過 `Jinja2` 渲染樣板，並透過 AJAX 動態拉取資料，無需重新整理頁面。
    *   身分驗證：網址帶有加密或專屬的 `user_id` 參數；並設有「開發者專區」允許輸入開發者密碼切換任意使用者檢視（並具備資料庫防呆驗證）。

## 二、 串接之 AI 功能與技術 (AI Integrations)

本專案採用了「雲端與地端 (Local) 混合」的多模型 AI 架構，根據不同任務的性質，將工作分派給最適合的語言模型。

### 1. 自然語言處理與閒聊 (Cloud AI - Gemini)
*   **功能描述**：作為機器人的「大腦前台」。當使用者輸入一般的文字、閒聊或是非特定結構的指令時，系統會理解其意圖並給予人性化的回應。
*   **串接技術**：使用 Google 的 **Gemini API**。
*   **所在位置**：實作於 `line_agent_service` 中。這個服務攔截特定指令後，將無法直接處理的自然語言對話交給 Gemini 生成回覆，確保對話的流暢性。

### 2. 意圖識別與工具呼叫 (Local AI - Hermes 3)
*   **功能描述**：當使用者輸入與台股操作相關的自然語言指令（例如：「我今天買了兩張台積電，價格是 850 元」），系統能精準擷取「股票代號」、「股數」與「單價」，並自動觸發背後的程式碼工具。
*   **串接技術**：使用本機端 **Ollama** 伺服器，運行 **`hermes3:8b`** 模型。Hermes 模型對 Function Calling (工具呼叫) 有極佳的支援，能將非結構化文字轉換為結構化的 JSON 參數並呼叫 Python 函式 (如 `buy_stock`, `sell_stock`)。
*   **所在位置**：實作於 `line_taicai` 的 `router.py` 中。

### 3. 盤後大盤趨勢分析 (Local AI - Hermes 3)
*   **功能描述**：系統會定時（或依指令）抓取今日台股大盤資料，並自動生成一篇專業的盤後分析報告。
*   **串接技術**：由 `line_taicai/core/ai_agent.py` 呼叫本機的 **`hermes3:8b`** 模型。AI 會讀取爬蟲抓下來的市場數據（成交量、漲跌幅、法人買賣超等），總結出當前市場情緒與未來關注焦點。

### 4. 個股健檢報告 (Local AI - Hermes 3)
*   **功能描述**：使用者可要求對特定股票進行「健檢」。系統會收集該股票近期的基本面與技術面資訊，交由 AI 綜合評估其體質與投資風險。
*   **串接技術**：同樣使用本機端 **`hermes3:8b`** 進行推論。由於資料極具隱私性或需要大量在地運算，採用 Local LLM 可確保資料不外流且免除 API 費用。

## 三、 系統網路與基礎設施 (Infrastructure)

*   **雙伺服器架構**：
    1.  `line_agent_service`：負責接收 LINE 伺服器傳來的 Webhook。
    2.  `line_taicai`：專注於台股業務邏輯與儀表板網頁伺服。
*   **內網穿透 (Cloudflared Tunnel)**：使用 Cloudflare 的 Quick Tunnel (`tools/cloudflared`) 將本機端 (localhost) 的服務暴露到外網，使 LINE 伺服器與使用者手機瀏覽器能安全地存取。其中 `line_agent_service` 自動更新隨機網址，而 `line_taicai` 則綁定於固定域名 (如 `handstarlinebot.win`)。
*   **背景常駐 (Launchd)**：使用 macOS 的 `launchctl` 管理伺服器的背景執行，確保系統重啟或發生錯誤崩潰時能自動重啟服務。
